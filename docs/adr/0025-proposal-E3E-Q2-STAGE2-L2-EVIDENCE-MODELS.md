## 4. API (coutures testées)
`RunDataCoverage.{from_s0_facts, from_record, from_bytes, to_record, to_bytes, sha256, semantically_equals}` · `RunSession.{open_for, from_record, from_bytes, ...}` · `RunSeal.{for_walk_forward, from_record, from_bytes, ...}` · `verify_run_evidence(coverage, sessions, seal, run_record_sha256, run_references=())` → `EvidenceChainFacts` (hashs seulement) · machine : `initial_state`, `apply_coverage`, `apply_session`, `apply_run_record`, `apply_seal(..., expected_session_count=None)`, `replay`, `RunEvidenceState.phase` ∈ {EMPTY, COVERED, IN_SESSIONS, RUN_RECORDED, SEALED} · `EvidenceRefusal` (44 codes fermés) / `EvidenceRefused` (picklable). Surface publique figée par un test.

**Graphe acyclique.** `coverage` ← `session_k` ← … ; `seal` → {`coverage`, `run`, `sessions`} ; `run` → `run_references` (vide pour le run historique). Un cycle (p. ex. un run qui cite le hash du sceau) est refusé (`CIRCULAR_REFERENCE`) ; un même hash ne peut pas jouer deux rôles (`HASH_ROLE_COLLISION`). L'ordre est un ordre de dépendance de hash, pas d'horloge.

**Invariants D7 (avant/après sans moteur).** Une session n'existe que si le digest de la trame présentée égale celui de la couverture (`FRAME_BEFORE_MISMATCH` sinon, aucune session produite) ; un Seal de calcul porte un digest « après » égal à celui de la couverture (`FRAME_AFTER_MISMATCH`), un Seal de récupération n'en porte pas (`FRAME_AFTER_MISSING` / `FRAME_AFTER_UNEXPECTED`). Aucun moteur ni worker n'est appelé ; les digests viennent de l'appelant.

## 6 bis. Ce que L2 vérifie, ce qu'il ne peut pas prouver
**Intégrité logique (vérifiée).** Pour des enregistrements fournis par l'appelant : schéma exact (clés, types, versions, instants, identités de run), octets exactement normatifs, cohérence des faits de trame (bornes, durée, grille, lignes), références croisées exactes (même run, même couverture, digests « avant » et « après », sessions `1..n` toutes présentes, uniques, listées par le sceau, octets du run), rôles de hash distincts, graphe de hash sans cycle, listes de sorties plausibles pour un disque, immuabilité. Une chaîne qui passe ces contrôles est **logiquement cohérente**.
**Observation réelle (NON prouvée).** Aucune lecture n'est observée : ni qu'un worker a reçu ou lu la trame, ni qu'aucun autre fichier de marché n'a été lu, ni que le digest « avant/après » a été calculé sur l'objet transmis au calcul. Les digests sont des déclarations de l'appelant.
**Chronologie forte (NON prouvée).** Aucun horodatage de confiance, aucun ordre vérifié des écritures, aucune durabilité. Une chaîne formellement correcte mais **fabriquée a posteriori** est indiscernable d'une chaîne produite dans l'ordre : c'est une DÉCLARATION cohérente, pas une preuve. **Exclusion de bout en bout (ABSENTE).** L2 ne dit rien de l'intersection entre la trame et `FINAL_HOLDOUT`, ne compare pas la couverture aux faits S0 recalculés par un auditeur, ne lit pas les sorties sur disque, ne produit aucun verdict `FRESH` / `NO_OVERLAP` / admission / Claim. ## 7. Risques résiduels et limites (non masqués)
- **R-fabrication** : la couverture reste une DÉCLARATION de l'orchestrateur ; ces modèles ne prouvent ni que la trame a été lue par les workers, ni qu'aucune autre trame n'a circulé.
- **R-chrono / R-conc** : `SEALED` dans la machine pure est une valeur cohérente, pas un fait ordonné ou durable ; le remplacement concurrent de `validation_run.json` (`save_atomic`, R9 6.2) n'est pas modélisé (la machine refuse un second run : plus strict que la réalité).
- **Sorties** : la liste `output_artifacts` est validée structurellement, jamais comparée à un système de fichiers (aucun I/O) ; l'exhaustivité contre `walk_forward/**` relève de l'auditeur (lot ultérieur).
- **Octets normatifs dupliqués** : l'égalité avec E3-C est testée sur des enregistrements types ; une évolution d'E3-C doit rejouer ce test.
- **`runtime` dans le hash** : deux couvertures qui ne diffèrent que par `runtime` ont des hashs différents ; la récupération doit utiliser `semantically_equals`, et le Seal lie le hash des octets exacts.
- **Pickle** : les objets repassent par la validation à la désérialisation (`__reduce__`), mais le format pickle n'est pas une entrée de confiance.
- **Pile de sessions** : `RunEvidenceState` revalide l'état entier à chaque transition (point unique des invariants) ; coût linéaire par transition (hash en cache), mesuré à moins de 3 s pour 200 sessions ; la borne 9999 de `session_index` est atteignable en théorie mais lente.
- **Non couvert** : `DERIVED`, `evidence_hash`, publication E3-C, lecture du disque, intégration à B3/B5/E3-J, D1-D9.

## Annexe A — programme indépendant de recalcul des vecteurs L2
Fichier de vecteurs : `0025-proposal-E3E-Q2-STAGE2-L2-VECTORS.json`. Recalcul sans importer le module (stdlib seule) :
```python
import json, hashlib, copy
def nb(r): return (json.dumps(r, sort_keys=True, ensure_ascii=False, indent=2, allow_nan=False) + "\n").encode("utf-8")
def sh(r): return hashlib.sha256(nb(r)).hexdigest()
src = json.load(open("docs/adr/0025-proposal-E3E-Q2-STAGE2-VECTORS.json", encoding="utf-8"))
wf = src["wf_chain"]; cov, ses, seal = wf["coverage_record"], wf["session_record"], wf["seal_record"]
assert sh(cov) == wf["coverage_sha256"] and sh(ses) == wf["session_sha256"] and sh(seal) == wf["seal_sha256"]
ses2 = dict(ses, session_index=2, resumed=True)
seal2 = dict(copy.deepcopy(seal), sessions=[{"session_index": 1, "session_sha256": sh(ses)}, {"session_index": 2, "session_sha256": sh(ses2)}])
recovery = dict(copy.deepcopy(seal), output_artifacts=[], frame_sha256_after=None, finalized_by_recovery=True)
print(sh(ses2), sh(seal2), sh(recovery))   # 62c28b3b… a93aefaa… 6b114fc9…
```
